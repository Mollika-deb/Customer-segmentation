# Customer Segmentation using Machine Learning
## Overview
This project applies unsupervised machine learning techniques to segment customers based on demographic and behavioral data. The goal is to identify meaningful customer groups and evaluate clustering results using appropriate validation techniques.

## Dataset

- Customer demographic and behavioral dataset
- Data was cleaned and preprocessed for analysis
- Features were selected and scaled to ensure reliable clustering

## Methods

- Data preprocessing and feature scaling (StandardScaler)
- Customer segmentation using K-Means clustering
- Hierarchical (Agglomerative) clustering for comparison
- luster evaluation using silhouette score
- Dimensionality reduction using PCA for visualization

## Key Results

- Identified distinct customer segments with clear behavioral patterns
- Optimal number of clusters determined using evaluation metrics
- Visualizations supported interpretation and comparison of clusters

## Tools
Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn
